# Changelog

Все заметные изменения Astreya Gate. Формат — «Keep a Changelog»:
секция `## [x.y.z]` с человекочитаемым описанием. Workflow релиза
автоматически вытаскивает секцию под тегом и кладёт её в Release —
именно этот текст видят пользователи в карточке обновления.

## [1.1.8] — 2026-08-24

**Добит краш «Карты» (продолжение 1.1.7).**

- Ещё два узла карты читали данные через пустую ссылку на первом рендере — тот же TypeError «reading 'ov'». Теперь все шесть узлов переписаны на безопасный доступ: карта рендерится с пустыми данными и наполняется метриками по мере опроса

## [1.1.7] — 2026-08-24

**Исправлен чёрный экран при открытии «Карты».**

- Причина: узлы карты на первом рендере получали пустые данные, и компонент падал с TypeError — React отмонтировал всё приложение целиком
- Узлы теперь устойчивы к пустым данным; добавлен страхующий ErrorBoundary: если какой-то раздел упадёт в будущем, остальное приложение продолжит работать, а упавший покажет причину и кнопку перезагрузки

## [1.1.6] — 2026-08-24

**Новая страница «Карта» — живая схема всего трафика (как n8n/Miro).**

- Вся маршрутизация на одном canvas: Браузеры / Приложения / Система → VPN-туннель и Мост → выходы (Нода, Напрямую, Прокси-пул)
- Связи подсвечиваются зелёным и анимируются, когда по ним реально идёт трафик; серые — не задействованы
- Живые метрики прямо на узлах: скорость приёма/отдачи, аптайм, счётчики пула, задержка ноды
- Клик по узлу — панель действий: включить/выключить туннель, сменить ноду (топ-8 по задержке), тумблер прокси браузеров, умная маршрутизация, переход в нужный раздел
- Узлы можно перетаскивать; колесо/тачпад — зум, пустое место — панорама

## [1.1.5] — 2026-08-24

**Трей-попап стал мини-приложением: VPN управляется без открытия окна.**

- Клик по иконке в трее → полноценный пульт: статус «Защищено/Выключено», кнопка питания, страна выхода и живая скорость
- Переключение нод прямо в попапе: список по задержке с флагами, зелёная точка — активная; смена ноды переподключает туннель сама
- Кнопка «Лучшая нода» — замеряет все ноды и подключает самую быструю
- Тумблер «Браузеры через VPN» теперь и в трее
- Панель выросла до 560px, список нод прокручивается, клик мимо — закрыть

## [1.1.4] — 2026-08-24

**Отказоустойчивость: VPN больше не может оставить без интернета.**

- Аварийная кнопка на рабочем столе — «Аварийное восстановление интернета.bat»: двойной клик сбрасывает всю сетевую обвязку (туннели, системный прокси, переменные) в базовое состояние. Работает без сети и без внешней помощи; пересоздаётся при каждом запуске приложения
- Watchdog туннеля: если активированный туннель упал, он поднимается автоматически (до 6 попыток, затем честное сообщение)
- Новый тумблер «Браузеры через VPN»: включает системный прокси Windows на порт туннеля — Chrome/Edge/Opera/Firefox ходят через ноду. Без прав администратора и без перехвата маршрутов
- Защита от «чёрного экрана»: при падении туннеля системный прокси браузеров отключается автоматически — интернет остаётся напрямую
- Стоп VPN снимает системный прокси сразу

## [1.1.3] — 2026-08-24

Исправлено: ноды из подписки «подключались», но не пропускали трафик.

- Причина: провайдер отдаёт каждую ноду в двух вариантах — XHTTP+TLS и Reality+Vision. XHTTP — транспорт Xray-ядра (NekoBox), движок sing-box его не поддерживает; выбирался именно он
- Теперь конвертер берёт совместимый вариант (Reality/Vision, WS, gRPC…), XHTTP-варианты пропускаются
- Ссылки с XHTTP дают понятную ошибку вместо молча неработающей ноды
- Обновление подписки больше не падает целиком из-за единичных неподдерживаемых нод — они пропускаются с записью в журнал
- Поддержан параметр ALPN в ссылках
- Порт уже занят другим VPN-клиентом (например NekoBox)? Теперь честная ошибка с подсказкой вместо ложного «успеха»

## [1.1.1] — 2026-08-24

**Исправлена подписка, которая не импортировалась:**

- Поддержка подписок в формате **v2rayN JSON** (массив полных конфигов — так отдают многие суб-конвертеры с `fmt=best`): VLESS/Reality, VMess, Shadowsocks, Trojan конвертируются в стандартные ссылки автоматически
- Умный выбор User-Agent при скачивании: если провайдер отвечает HTML-заглушкой, повторяем запрос с UA v2rayN, затем через мост — как это делают NekoBox и v2rayN
- Проверено на реальной подписке: все ноды извлекаются и валидируются

## [1.1.0] — 2026-08-23

**Системный VPN (TUN-режим) — как у Happ:**

- Новый тумблер «Системный режим» на странице VPN: перехватывает весь трафик Windows через виртуальный адаптер — работает даже для приложений без поддержки прокси
- Права администратора запрашиваются один раз при включении; дальше старт/стоп мгновенно, без UAC
- Режимы маршрутизации («Умный», «Белый список») работают и в системном режиме: RU-сервисы идут напрямую, LAN не трогается
- DNS перехватывается туннелем (hijack порта 53 + DoH через прокси) — утечек DNS нет
- Совместимость с sing-box 1.13: новый формат DNS-серверов (legacy отключается в 1.14)
- Исправление: Reality-ноды без параметра fp теперь автоматически получают uTLS (chrome) — иначе движок отказывался их запускать

## [1.0.0] — 2026-08-23

**Первый релиз Astreya Gate** (форк Clod-Helper, переработан):

- Прокси-мост: пул до 5 upstream'ов с failover, цепочки прокси (hop-1), SOCKS5-поддержка, счётчики трафика и живые скорости
- VPN-менеджер на движке sing-box: подписки с автообновлением, одиночные конфиги, 6 протоколов (VLESS/Reality, VMess, SS, Trojan, Hysteria2, TUIC), delay-тесты нод
- Маршрутизация по сервисам: Claude — через платный прокси, всё остальное — через системный/VPN; строгие закрепления без смены выходного IP
- «Прокси по умолчанию»: трафик без закреплений не жжёт платный трафик
- Браузеры через PAC: выбранные сайты через прокси, остальные напрямую
- Killswitch через Windows Firewall — физический запрет обхода прокси
- Deep-links: astreya:// и совместимость с happ://add; импорт из буфера
- Режимы туннеля: «Всё через VPN» / «Умный» (RU напрямую) / «Белый список»
- Автообновление с проверкой Ed25519-подписи
